P11714 [清华集训 2014] 主旋律

dag 反演的一个板子题吧，但是不会，在这里写一下 dag 反演，当是学习笔记了

问题是求解强连通导出子图数量，这个本质上是导出子图总数 - 缩点后 dag 总数

为什么 dag 是优于强连通的？

因为 dag 可以选出极大 0 度数子集，然后变成子问题求解

考虑一个更简单的问题吧： dag 导出子图计数：

考虑我们可以枚举入度为 0 的节点，然后取出这些点以后剩下点仍然需要构成 dag。

lS=∑T⊆SlS∖T2ET,S∖Tl_S = \sum\limits_{T \subseteq S} l_{S\setminus T} 2^{E_{T, S \setminus T}} lS​=T⊆S∑​lS∖T​2ET,S∖T​

这个东西并不对，因为不能保证 S∖TS \setminus TS∖T 中不存在 0 度数的点。

考虑容斥： fTf_TfT​ 表示 SSS 中恰好只有 TTT 中是 0 度数的点， gTg_TgT​ 表示钦定 TTT 中是 0 度数的点的条件下后者的值。

gS=∑S⊆TfTg_S = \sum\limits_{S \subseteq T} f_T gS​=S⊆T∑​fT​

子集反演一下就是：

fS=∑S⊆T(−1)∣T∣−∣S∣gTf_S = \sum\limits_{S \subseteq T} (-1)^{|T| - |S|} g_T fS​=S⊆T∑​(−1)∣T∣−∣S∣gT​

然后有恰好了就可以丢进去一开始那个式子：

lS=∑T⊆S,T≠∅fTl_S = \sum\limits_{T \subseteq S, T \neq \empty} f_T lS​=T⊆S,T​=∅∑​fT​

带入定义：

lS=∑T⊆S,T≠∅∑T⊆R(−1)∣R∣−∣T∣gRl_S = \sum\limits_{T \subseteq S, T \neq \empty} \sum\limits_{T \subseteq R} (-1)^{|R| - |T|} g_R lS​=T⊆S,T​=∅∑​T⊆R∑​(−1)∣R∣−∣T∣gR​

交换求和次序：

lS=∑R⊆S,R≠∅(−1)∣R∣gR∑T⊆R,T≠∅(−1)∣T∣l_S = \sum\limits_{R\subseteq S, R \neq \empty} (-1)^{|R|} g_R \sum\limits_{T\subseteq R, T\neq \empty} (-1)^{|T|} lS​=R⊆S,R​=∅∑​(−1)∣R∣gR​T⊆R,T​=∅∑​(−1)∣T∣

后面的部分考虑组合意义：

lS=∑R⊆S,R≠∅(−1)∣R∣gR([R=∅]−1)l_S = \sum\limits_{R\subseteq S, R \neq \empty}(-1)^{|R|} g_R ([R = \empty] - 1) lS​=R⊆S,R​=∅∑​(−1)∣R∣gR​([R=∅]−1)

整理，带入 ggg：

lS=∑R⊆S,R≠∅(−1)∣R∣+1lS∖T2ET,S∖Tl_S = \sum\limits_{R\subseteq S, R \neq \empty}(-1)^{|R| + 1} l_{S\setminus T} 2^{E_{T, S \setminus T}} lS​=R⊆S,R​=∅∑​(−1)∣R∣+1lS∖T​2ET,S∖T​

到强连通子图的情况呢：

考虑如果我们可以算出把一个集合 TTT 划分成若干个互不相连的 SCC，记为 gTg_TgT​ 的话，是否是好算的？

似乎要知道划分成了多少个才有可能计算，修改定义为：

gTg_TgT​ 表示将 TTT 划分为若干个独立的 SCC 后，奇数方案数量减偶数方案的数量。

2ES,S=∑T⊆S,T≠∅gT2ET,S∖T+ES∖T,S∖T2^{E_{S,S}} = \sum\limits_{T\subseteq S, T \neq\empty} g_T 2^{E_{T, S\setminus T} + E_{S\setminus T, S\setminus T}} 2ES,S​=T⊆S,T​=∅∑​gT​2ET,S∖T​+ES∖T,S∖T​

也就是说：

gS=2ES,S−∑T⊊S,T≠∅gT2ET,S∖T+ES∖T,S∖Tg_S = 2^{E_{S,S}} - \sum\limits_{T\subsetneq S, T \neq\empty} g_T 2^{E_{T, S\setminus T} + E_{S\setminus T, S\setminus T}} gS​=2ES,S​−T⊊S,T​=∅∑​gT​2ET,S∖T​+ES∖T,S∖T​

顺便定义 fSf_SfS​ 表示将 SSS 缩为一个唯一的 SCC 的方案数，然后拆开这个容斥即可。

fS=gS−∑T⊊S,lowbit(T)=lowbit(S)fTgS∖Tf_S = g_S - \sum\limits_{T\subsetneq S, lowbit(T) = lowbit(S)} f_T g_{S \setminus T} fS​=gS​−T⊊S,lowbit(T)=lowbit(S)∑​fT​gS∖T​

Min Max 容斥

MinMax 反演常见于求解期望，因为在期望意义下，一系列事件发生一件和全部发生的难度往往补等同。

基础式子：

min⁡(S)=∑T⊆S,T≠∅(−1)∣T∣−1max⁡(T)\min (S) = \sum\limits_{T\subseteq S, T \neq \varnothing} (-1)^{|T| - 1} \max (T) min(S)=T⊆S,T​=∅∑​(−1)∣T∣−1max(T)

以及扩展意义下的：

k-min(S)=∑T⊆S,T≠∅(−1)∣T∣−k(∣T∣−1k−1)max⁡(T)\text{k-min} (S) = \sum\limits_{T\subseteq S, T \neq \varnothing} (-1)^{|T| - k} \binom {|T| - 1}{k - 1} \max (T) k-min(S)=T⊆S,T​=∅∑​(−1)∣T∣−k(k−1∣T∣−1​)max(T)

min⁡max⁡\min \maxminmax 交换成立，在期望意义下成立。

P4707 重返现世

化用期望意义下的 MinMax：

E(k-max(S))=∑T⊆S,T≠∅(−1)∣T∣−k(∣T∣−1k−1)E(min⁡(T))E(\text{k-max} (S)) = \sum\limits_{T\subseteq S, T \neq \varnothing} (-1)^{|T| - k} \binom {|T| - 1}{k - 1} E(\min (T)) E(k-max(S))=T⊆S,T​=∅∑​(−1)∣T∣−k(k−1∣T∣−1​)E(min(T))

不难得出有

E(min⁡(T))=m∑i∈TpiE(\min(T)) = \frac{m}{\sum\limits_{i\in T} p_i} E(min(T))=i∈T∑​pi​m​

直接枚举子集 TTT 不是很好，注意到这个东西类似一个背包：记录 fi,j,kf_{i,j,k}fi,j,k​ 表示前 iii 个 ∑pi=j\sum p_i = j∑pi​=j，容斥下标为 kkk 的情况下容斥系数的和。

当前这个 ppp 不选 ： fi,j,k←fi−1,j,kf_{i,j,k} \leftarrow f_{i-1, j, k}fi,j,k​←fi−1,j,k​

选：

fi,j,k←−fi−1,j−p,k+fi−1,j−p,k−1f_{i,j,k} \leftarrow - f_{i-1,j-p,k} + f_{i-1,j-p,k-1} fi,j,k​←−fi−1,j−p,k​+fi−1,j−p,k−1​

然后 dp 计算转移即可。

P3600 随机数生成器

给定随机序列和区间集合，问区间最小值集合的最大值。

外层套用 MinMax 然后转化成问若干个最小值集合的最小值，本质就是问集合并集的最小值，这个只和并集大小有关，预处理计算即可。
