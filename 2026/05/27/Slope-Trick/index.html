P12074 [OOI 2025] The arithmetic exercise

正序考虑的话一个数字的贡献并不明显，倒序的话是简单的。

初始 nnn 个位置放进去都是正的，放进去一个位置之后下一位贡献翻转。

不关心位置只关心数量，简单有一个 fi,jf_{i, j}fi,j​ 表示后 iii 个剩余 jjj 个负位的最值。

fi,j=max⁡(fi−1,j−1+ai,fi−1,j+1−ai)f_{i, j} = \max (f_{i - 1, j - 1} + a_i, f_{i - 1, j + 1} - a_i) fi,j​=max(fi−1,j−1​+ai​,fi−1,j+1​−ai​)

先预先钦定选择负项，变成：

fi,j=max⁡(fi−1,j−1+2×ai,fi−1,j+1)f_{i, j} = \max (f_{i - 1, j - 1} + 2 \times a_i, f_{i - 1, j + 1}) fi,j​=max(fi−1,j−1​+2×ai​,fi−1,j+1​)

偏移一位：

fi,j=max⁡(fi−1,j−2+2×ai,fi−1,j)f_{i, j} = \max (f_{i - 1, j - 2} + 2 \times a_i, f_{i - 1, j}) fi,j​=max(fi−1,j−2​+2×ai​,fi−1,j​)

考虑这个的本质似乎是把原先的图像平移然后取 max⁡\maxmax，然后这个东西本身是上凸的。

slope trick：

上凸函数的差分数组是单调递减的，这个东西可以丢一个 multiset 维护。

可以视为一个 O(1)O(1)O(1) 的改动实现。

P3642 [APIO2016] 烟花表演

fi,jf_{i,j}fi,j​ 表示 iii 子树内全部到 jjj 的贡献计算，这个显然是下凸的。

合并是逐点加，这个东西如果我们维护斜率每一个拐点，由于对于下凸函数的斜率来说也是逐点加，所以可以看成拐点的合并。

然后考虑加入一条边，这个的贡献是一个绝对值函数。

对于原先凸壳里面一条斜率大于 1 的直线，我们从其最左端出发转移到尾部一定优秀，因为绝对值函数斜率最大为 1，也就是尾部大于 1 的部分全部删除。

然后考虑前面的部分，如果斜率小于等于 -1，叠加之后一定是最右端最优，所以这部分保持不变，中间部分平移即可。

可并堆维护或者启发式合并堆。
