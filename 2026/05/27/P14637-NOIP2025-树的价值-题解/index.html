P14637 [NOIP2025] 树的价值 题解

发表于2026-05-27|更新于2026-06-04
|浏览量:

浪费了一天的一个题，但是真的好啊。

拿到这个题想到一个 dp：

fi,j,kf_{i,j,k}fi,j,k​ 表示 iii 子树内 MEX=j\text{MEX} = jMEX=j 且拥有 kkk 个可以自由放置的位置，这个看起来就很不好转移，实际上一点也不好转移。

大概就是一个背包，看写法可以做到 n3n^3n3 或者 n4n^4n4 的做法，说到底在这个状态设计上面就已经输掉了吧，这个的状态数是 n3n^3n3 的。

转换一下思路：因为是 MEX\text{MEX}MEX，似乎我们可以拆分贡献，观察一下原来的 dp。

注意到其实我们的 MEX\text{MEX}MEX 是从最大的儿子的 MEX\text{MEX}MEX 为基础再利用一些自由点扩展得到的，我们将这个儿子标记为重儿子，观察贡献的形态。

考虑每一个点的贡献，都一定可以是向上找到一个重链，贡献这条重链和当前点到根的路径交链长度，对此我们只需要让这个点成为链的最低点的 MEX\text{MEX}MEX 即可。

那么我们写出一个这样的方程：

fi,j,kf_{i,j,k}fi,j,k​ 表示 iii 子树中，上接了一条长度 kkk 的链，到根路径最长链为 jjj 的贡献和。

这个东西我们的 dp 应该是好做的，具体的就是选择一个增量最大的重儿子然后转移。

现在状态是瓶颈： nm2nm^2nm2，考虑优化，用转移时间换状态数。

我们只保留 kkk 等于 111 的情况和 k=jk = jk=j 的情况，由状态不存在 k>jk > jk>j。

考虑 1<k<j1 < k < j1<k<j 的情况计算：我们在 k=1k = 1k=1 的时候向后找到一个合法的 k=jk = jk=j，也就是找到所有的 jjj 级儿子，直接钦定这整条路径。

考虑对于每一个 j−1j - 1j−1 级儿子 ttt，我们有如下式子：

fi,j,1←ft,j,j+∑p∈Si,tfp,j,1+j×(j−1)f_{i,j,1} \leftarrow f_{t,j,j} + \sum\limits_{p \in S_{i, t}} f_{p,j,1} + j \times (j - 1) fi,j,1​←ft,j,j​+p∈Si,t​∑​fp,j,1​+j×(j−1)

其中 Si,tS_{i,t}Si,t​ 表示链 iii 到 ttt 的邻域。

另外一个平常的式子是：

fi,j,j←fs,j+1,j+1+∑t∈Si,t≠sft,j,1f_{i,j,j} \leftarrow f_{s,j + 1,j + 1} + \sum\limits_{t\in S_i, t\neq s} f_{t, j, 1} fi,j,j​←fs,j+1,j+1​+t∈Si​,t​=s∑​ft,j,1​

这个东西可以倒序枚举 jjj 拍扁一维，另外一维可以 dfs + 树状数组维护，注意到每个点最多只有 mmm 个祖先，所以祖孙对数量是 nmnmnm 的，直接维护是 nmlog⁡nnm\log nnmlogn 的。

当然，这个东西也可以向下维护 jjj 层的答案，就变成一个标准的长剖优化 dp 式子，复杂度是 nmnmnm。
