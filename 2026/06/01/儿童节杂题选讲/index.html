CF765F

区间一维最近点对。

先钦定大小关系构成顺序对，反向同理讨论即可，考虑对于一个点 iii，可以与它产生贡献的 j>ij > ij>i 有哪些可能性。

显然 j=i+1j = i + 1j=i+1 一定是一种可能贡献点对，因为区间可以是 [i,i+1][i, i + 1][i,i+1]。

考虑下一个要优化这个结构那么一定有 ak<ai+aj2a_k < \frac{a_i + a_j}{2}ak​<2ai​+aj​​，也就是距离 aia_iai​ 的值减半，否则选择 (k,j)(k, j)(k,j) 构成一对一定优秀于 (i,k)(i, k)(i,k)。

那么合法点对数量就是 nlog⁡Vn\log VnlogV 级别的，然后二维数点即可。

CF1270G

序列 aaa 满足 i−n≤ai≤i−1i - n \le a_i \le i - 1i−n≤ai​≤i−1，选出子序列和为 0。

移项，有 1≤i−ai≤n1 \le i - a_i \le n1≤i−ai​≤n，启示我们在图上考虑这个问题。

我们连边 i→i−aii \to i - a_ii→i−ai​，这样序列构成了一个内向基环树森林，每个环就是一个和为 0 的子序列。

P2757

问排列是否存在 N≤3N \le 3N≤3 的等差子序列，显然等价于 N=3N = 3N=3。

扫描线，考虑当前左边的权值线段树，对于一个 ddd，我们需要考虑 i−di - di−d 和 i+di + di+d 在左右的情况。

两者同时在左边和同时在右边显然无法构成等差序列，需要一左一右，在权值线段树上考虑这个东西就是这两个东西不能同时为 0 或者同时为 1。

那么就是这个不是关于 aia_iai​ 在权值线段树上回文，正反维护一下哈希即可。

P9128

每个点的贡献是一个正比例函数，问遍历全树回到/不回到根节点的最小时间最小贡献和。

影响是子树的访问顺序，拆除贡献式子发现贡献是交错的，相邻推导出不等式然后排序即可。

不回到根节点的情况可以简单拆分贡献讨论。
