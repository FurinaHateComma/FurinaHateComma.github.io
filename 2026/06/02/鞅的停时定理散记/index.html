鞅的停时定理散记

发表于2026-06-02|更新于2026-06-04
|浏览量:

核心思想：

在解决一类求解期望步数/时间的问题时，如果对于任何合法状态都存在一个不变量，我们对于这个映射叠加时间影响构造势能函数，使得一步操作的期望势能差为一个常数 CCC，那么就可以通过起始和结尾状态势能差计算期望时间。

省流：构造势能函数使得期望势能差为定值，答案就是首尾势能差除以单步势能差。

CF1025G

有 nnn 个公司构成森林，公司只可以是根或者叶子。

每次随机选择两个根，将一个根设为另外一个根的叶子，同时将这个不再是根的儿子全部独立为根。

注意到这个东西相对独立且无关标号，这个东西不妨暂定是 ∑f(x)\sum f(x)∑f(x) 状物。

然后我们列出一次的势能差：

2×δf=f(x+1)+yf(0)+f(y+1)+xf(0)−f(x)−f(y)2\times \delta f = f(x + 1) + y f(0) + f(y + 1) + x f(0) - f(x) - f(y) 2×δf=f(x+1)+yf(0)+f(y+1)+xf(0)−f(x)−f(y)

钦定一个常数 c=1c = 1c=1，将 xxx 的部分和 yyy 的部分对称分离。

f(x+1)+xf(0)−f(x)=1f(x + 1) + x f(0) - f(x) = 1 f(x+1)+xf(0)−f(x)=1

因为对于势能我们只关心差，不关心具体和斜率，所以我们可以钦定两个值，这里只钦定 f(0)=0f(0) = 0f(0)=0，然后可以用数学知识求解这个东西，表过。
