发表于2026-06-04|更新于2026-06-04

树上随机游走，顾名思义就是在树上维护一个点的游走过程，这个点以均等的概率前往邻域内一点，似乎这件事会带上期望概率考察，本身可以套上 dp，或者使用鞅停解决。

P5643 [PKUWC2018] 随机游走

min⁡max⁡\min\maxminmax 反演完就剩下一个这样的问题：对于一颗树和一个点集 TTT，询问游走走到点集内的期望步数。

先假设 fpf_pfp​ 表示 ppp 点的答案，那么有：

fp=ffap+∑ftd+1f_p = \frac{f_{fa_p} + \sum f_t}{d} + 1 fp​=dffap​​+∑ft​​+1

边界情况是在点 x∈Tx \in Tx∈T 上，此时 fx=0f_x = 0fx​=0，但是这个是循环，不好递推。

猜测这个东西是一个线性递推，fp=kpffap+bpf_p = k_p f_{fa_p} + b_pfp​=kp​ffap​​+bp​，然后列出来：

dpfp=ffap+∑ft+dpd_p f_p = f_{fa_p} + \sum f_t + d_p dp​fp​=ffap​​+∑ft​+dp​

同乘 ddd 消去分式：

dpfp=ffap+∑fpkt+∑bt+dpd_p f_p = f_{fa_p} + \sum f_pk_t + \sum b_t + d_p dp​fp​=ffap​​+∑fp​kt​+∑bt​+dp​

分离两侧 ppp 和 fapfa_pfap​

(dp−∑kt)fp=ffap+∑bt+dp\left( d_p - \sum k_t \right) f_p =f_{fa_p} + \sum b_t + d_p (dp​−∑kt​)fp​=ffap​​+∑bt​+dp​

整理：

fp=ffap+∑bt+dpdp−∑ktf_p = \frac{f_{fa_p} + \sum b_t + d_p}{d_p - \sum k_t} fp​=dp​−∑kt​ffap​​+∑bt​+dp​​

提取 kpk_pkp​ 和 bpb_pbp​

kp=1dp−∑kt, bp=∑bt+dpdp−∑ktk_p = \frac{1}{d_p - \sum k_t},\ b_p = \frac{\sum b_t + d_p}{d_p - \sum k_t} kp​=dp​−∑kt​1​, bp​=dp​−∑kt​∑bt​+dp​​

先下往上跑出每一个点的 kkk，bbb，然后向下算每个点的期望。
