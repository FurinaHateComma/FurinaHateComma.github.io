二中集训补题合集

Day1

概述：A 差了一步，B 想歪了，C 垃圾题什么时候想起来什么时候补。

A

从小到大贪心是错误的，但是并不显然，考虑从大往小倒着贪心：

对于一个需求 bbb，如果我们当前有能够满足其的 aaa 直接用一定是对的，因为 aaa 的效果最大化了，否则我们只能拆成两个。

最后的一个需求可能要留着拆几步消耗完 aaa，不知道为什么赛事想的是正着处理这一小步。

B

赛事想到图论建模和势能去了，有点歪。

因为路径信息所以是点分治，考虑这个点分治，我们实际上是过中心或者通过之间的叶子边通行。

中心可以一次 dij 解决，叶子边可能很多，不好一次 dfs，考虑通过加空边拆分成若干度数 3 的节点。

Day2

概述： B < A <<<<< C ? 磕 A 还是差最后一小步？可能不小

B

这个东西是一个相当于对小数的二进制拆分，然后不好做。

考虑模 SSS 意义下，这个东西其实可以有一个 fpf_pfp​ 从 f2pf_2pf2​p 推导过来的道理（可以理解为模拟竖式）。

然后我们可以吧这样的关系作为一条转移边，就构成了基环树森林。

最后这个东西在环上可以算，算出来推导到链就做完了，

A

似乎差分约束意义下是可以做的，但是最后一步的模拟意义还欠思考。

额首先这个东西有一个差分约束的意义，然后在这个意义下我们可以通过糖水不等式和一些发现快速算出误差为 1 的答案。

然后考虑求答案，我的想法是倍增模拟最短路，实际上似乎可以直接倍增找后 t 个可行点然后顺手标记就搞定了。

C

噔噔咚！

对于任何情况都有解 和 要在线图上考虑这个问题是首先的两个思考。

线图上似乎是一个团集合，并且有交，我们补齐这个二分图为一个 kkk 正则二分图来满足一些性质。

因为可以重边，补齐是简单的，如果我们注意到任意情况都有解，那么补齐后的问题是有解的。

我们需要一个补边的顺序，或者说至少是相对顺序来求解这个问题。

考虑在线图上边定向，那么我们显然希望每个点的入度和出度都恰好是 k−1k - 1k−1，因为这样我们就可以确定这个点。

这个定向是一个新问题，其实是（冷门）经典模型：一个 kkk 正则二分图的边色数等于 kkk，我们对原二分图染色每个边，然后在线图上定向的时候按照颜色的全序关系定向即可。

在接下来，我们认为 a→ba \to ba→b 是优先确定 aaa 的颜色。

那么我们其实需要保障的是在定向的期间，每个点（边）的可选颜色数始终大于其入度，这个在初始一定满足的。

我们枚举颜色，考虑当前选取一个确定颜色，并在线图上取出有这个颜色的点的导出子图，我们在这个子图上选取一个点集，需要满足什么条件？

独立性显然，这个东西要是一个独立集，我们还需要保证每个点的可选颜色数始终大于其入度。

对于这个东西，考虑有子图中的点的颜色数减少了，那我们一定要其入源集合减小：我们要求每一个不在点集的点，都有点集内一点指向其的边。

这个东西在图论里面被称为图的一个 核，考虑核怎么求，回到原图考虑（真的不是左手倒右手）：

独立集的要求：在原图上是一个 匹配。

在线图上：对于任何一个不在核 KKK 里的点 eee，必定存在一条有向边，连接着 eee 和核里的某个点。

它的本质是：eee 被核里某个优先级更高的点给压制了。

  • 没进核的点 eee →\to→ 原图里没被选中的边 e=(u,v)e = (u, v)e=(u,v)。
  • 核里的高优先级点 →\to→ 原图里的匹配边。
  • eee 被压制 →\to→ 在顶点 uuu 或 vvv 处，必定有一条排名比 eee 靠前的边，被选入了匹配 MMM。

也就是说：对于任何一条落选的边 (u,v)(u, v)(u,v)，要么 uuu 匹配到了自己更喜欢的边，要么 vvv 匹配到了自己更喜欢的边。

那么这个东西我们就转化成了一个稳定婚姻问题，然后就做完了。

补充两个提到的东西：

kkk 正则二分图的 kkk 染色：对每个联通分量考虑：

  • kkk 为奇数，我们直接跑一个匹配变成偶数。
  • kkk 为偶数，我们将图划分成若干个欧拉回路，每个欧拉回路交替染色把图划分成两个子图。

稳定婚姻问题：

每个右点记录一个当前选择，左点维护一个待取队列。

如果左点的某个右点被取了，那么我们就看对于这个右点谁更优，维护一下即可。

Day3

终于不是区了！，但是还是 B < A <<<< C

B

不难想到状压，状压之后这个显然是存在一个划分点，这个东西大抵是有一个显然的单峰的性质。

考虑怎么快速计算贡献？似乎是一个精细实现的前缀和状物。

记录 fi,j,kf_{i,j,k}fi,j,k​ 表示前 iii 个 jjj 对颜色 kkk 的贡献，然后大概就做完了。

A

首先寻求一个条件的充要条件：对于位置 xxx 和位置 yyy 其向左找到第一个比他大的点，记为 lxl_xlx​ 和 lyl_yly​，条件等价于 lx=lyl_x = l_ylx​=ly​。

枚举这个取到的点，贡献计算如下分讨：

  • l=0l = 0l=0 此时，xxx 和 yyy 是前缀最大值，这在排列中发生的概率是 1xy\frac{1}{xy}xy1​

  • l≠0l \neq 0l​=0，那么我们抽离区间 [l+1,x][l + 1, x][l+1,x] 和 [l+1,y][l + 1, y][l+1,y] 的情况，这两者的限制都变成了 xxx 和 yyy 是各自区间的最大值：那么发生的概率就是 1(x−l)(y−l)\frac{1}{(x - l)(y - l)}(x−l)(y−l)1​。

考虑后者的求和是瓶颈，考虑解耦 x,yx, yx,y 裂项，记 d=y−xd = y - xd=y−x：

∑l=1min⁡(x,y)1(x−l)(y−l)=1d∑l=1min⁡(x,y)1y−l−1x−l\sum\limits_{l = 1}^{\min (x, y)} \frac{1}{(x - l)(y - l)} = \frac{1}{d} \sum\limits_{l = 1}^{\min (x, y)} \frac{1}{y - l} - \frac{1}{x - l} l=1∑min(x,y)​(x−l)(y−l)1​=d1​l=1∑min(x,y)​y−l1​−x−l1​

分裂后形如两个调和级数差，预处理即可。

C

题目显然提示我们同余拆点，对于每一条环限制上的点进行同余拆分，这样新点数是 (∑li)2(\sum l_i)^2(∑li​)2 级别的。

考虑如下几种形式的转移在 dijkstra 中如何做到正确复杂度：

  • 安全点到安全点：

    这部分可以直接 dijkstra 简单维护。

  • 安全点到危险点：

    考虑一条边，我们拆分后边数显然爆炸，所以启发我们一起考虑这些部分。

    对于一个危险点，在考虑等待后显然只有最早的安全点可以更新，那么我们这样对于每个危险点产生 lll 的复杂度，可以接受。

  • 危险点到安全点：

    抵达安全点后我们关心的显然只有时间，最小时间。

    我们可以对每个环建立一个虚点，用来承接离开前往安全点的边，复杂度不变。

  • 危险点到危险点：

    • 同环的显然建边跑复杂度不变。

    • 考虑不同环两点 x,yx, yx,y，周期分别为 lx,lyl_x, l_ylx​,ly​

      我们进入环的时候有一个更有用的性质：要么我们就直接进入，要么我们就等待危险点抵达后跟在后面。

      可以证明存在一种方案满足可以达成后者且不被当前环撞：我们先走到对面，然后等待对面的粒子过来的时候回到原环，然后再回去。

      有一个问题：回来的时候撞了怎么办，那我们只能在当前环先转若干圈，然后再执行上面的做法，

      考虑我们转了一圈后，如果仍然会撞，那么其实固定在撞的那一瞬间是同余等价的，回退若干步仍然有等价性，也就是说我们走到了一个等价状态，我们之后再转若干圈也仍然无法做到。

      那么我们一条边的转移其实隐含了后者的状态是同余等价的，那么其实我们一条边只松弛一次是对的，这样做就可以通过。

好阴啊草。

C

等价类分治题，有趣。

考虑这个东西（替换）的贡献很难叠加，那么只能考虑等价类分治。

首先把所有的修改丢进 ODT 里面，然后就变成若干个节点 (s,t,l,r,p,v)(s, t, l, r, p, v)(s,t,l,r,p,v) 形如：时间区间 [s,t][s, t][s,t]，行 ppp 的区间 [x,y][x, y][x,y] 有 ap,j=va_{p, j} = vap,j​=v，并且保证不存在同时时间交和空间交的区间。

ODT 告诉我们这里最多有 qqq 个等价类。

这样之后我们就可以把这些东西全部按照列挂载在线段树上，得到 qlog⁡nq \log nqlogn 状物的修改节点，这里我们的挂载是包含了不完全包含的节点部分。

这样我们就可以直接时间扫描线枚举这个东西，然后查区间 bbb 最值算，丢进 multisetmultisetmultiset 里面计算即可，最后是 log2log^2log2 的。
