A

问区间翻转后相邻差对 0 取 max⁡\maxmax 求和。

简单前缀和维护即可。

B

问树上边集选中与否权积乘最大匹配数之和。

匹配可以变成一个树上的简单 dp，但是边集计数比较困难。

我们需要知道可以让这个点空着不影响匹配的边集权积和，方案的总和，答案和。

假设这三者分别为 F,G,LF, G, LF,G,L，当前合并的子树值为 f,g,lf, g, lf,g,l，边权为 a,ba, ba,b

那么有：

F′→(bg+a(g−f))FF' \to (bg + a(g - f)) F F′→(bg+a(g−f))F

G′→G(a+b)gG' \to G(a + b) g G′→G(a+b)g

匹不匹配不影响原先答案分配率计算，匹配独立求和。

L′→L(a+b)g+G(a+b)l+FafL' \to L (a + b) g + G (a + b) l + F a f L′→L(a+b)g+G(a+b)l+Faf

递推得到最终 LLL 即为答案。

C

问矩阵，矩阵值域 [0,2][0, 2][0,2] 选择点集公开使得某行在按照 (si,−i)(s_i, -i)(si​,−i) 双关最大的行恰好为 rrr。

注意到判定关于一个双关排序后的最大值，枚举这个具体的最大值是 nmKnmKnmK 的，考虑那些人取不到。

能否取得到只关系于这个位置可能取到的最大值。

考虑按照 (si,−i)(s_i, -i)(si​,−i) 大小去扫描，这样我们每次从当前节点的未揭晓贪心试着去改即可。

变成一个插入删除 kkk 小值和或者 点修 kkk 小值和，随便写一个数据结构都可以维护。

D

跳跃：跳到编号小于当前的，与当前点权绝对差最大的，相同取编号最大的位置。

每次剖离子数组问跳跃次数。

考虑跳跃的过程，第一步一定是跳跃到一个 min⁡\minmin 或者 max⁡\maxmax，接下来我们是交替跳两者。

按 rrr 扫描线，考虑跳跃的开始点分别落点为 min⁡\minmin 或者 max⁡\maxmax 时的值，假设为 (F,G)(F, G)(F,G)。

扫描的时候，每次只有当我成为从某个点开始的前缀最大值或者最小值才产生改变。

具体的，我们可以维护这个单调栈区间，本质操作是：

(F,G)→(G+1,G)(F, G) \to (G + 1, G) (F,G)→(G+1,G)

(F,G)→(F,F+1)(F, G) \to (F, F + 1) (F,G)→(F,F+1)

(F,G)→(G+1,F+1)(F, G) \to (G + 1, F + 1) (F,G)→(G+1,F+1)

三者本质都是广义矩乘操作，存在 TagTagTag 维护方式。
